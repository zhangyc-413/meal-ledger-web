# Ivan 饭钱账本

一个采用 Notion 数据库式表格的轻量饭钱账本。

- 输入名称和金额即可记账
- 日期默认当天，也可以在新增或已保存的记录中直接调整
- 记录按日期由近到远排列，同一天内后添加的记录优先显示
- 新增花费自动按两人平分，充值保留原金额
- 自动区分花费与充值，并实时计算余额
- 每条记录显示可调整日期和当时余额
- 支持导入、导出 JSON 备份
- 数据仅保存在当前浏览器，不上传到服务器

## 本地运行

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
```

## 港币记账

- 在「本笔币种」选择人民币或港币；花费、充值均可使用港币。
- 港币按中国银行（中国内地）的**现汇买入价**折成人民币。牌价单位是每 100 港币，程序除以 100 后使用。
- 先换算人民币，再按原规则将花费平分、四舍五入到元；充值不平分。余额和汇总始终以人民币显示。
- 每笔港币记录保存原金额、使用的汇率、牌价时间和来源。改日期、刷新汇率都不会重算已保存的金额。
- 补记旧日期也使用保存时页面显示的牌价，不查询历史汇率。
- 现有人民币记录及 v1 备份兼容；v2 备份包含港币换算信息。
- 牌价在部署时及 GitHub Actions 每 6 小时的定时部署中更新，可能因 Actions 排队延迟；界面显示实际牌价时间，不承诺实时。
- 浏览器读取同源 `boc-hkd.json`，不依赖第三方汇率代理。获取失败时保留上次牌价；超过 48 小时须明确确认才能使用。没有有效牌价时不能保存港币记录，人民币不受影响。
- 账目仍只保存在浏览器，部署和汇率更新不包含个人账目。

验证：`pnpm test`、`pnpm build`。手动刷新牌价：`node scripts/update-boc-rate.mjs`。
